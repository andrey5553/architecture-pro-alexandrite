# Jaeger в Docker с сервисами

## Описание
Развертывание Jaeger локально с двумя сервисами, которые:
1. service1 взаимодействует с service2
2. service1 отправляет трейсы в Jaeger

## Требования
- тестировалось в Windows11
- powershell
- Docker

## Установка

### 1. Запуск Minikube 
`services/local/start.ps1` # Запуск инфраструктуры (Jaeger и Prometheus), Сборка, запуск Service2, Сборка, запуск Service1 (в отдельных окнах)
[результат запуска](../Task3/png/запуск%20сервисов.png)

## Проверка работы

### Доступ к Jaeger UI
1. Откройте в браузере: http://localhost:16686 # должно отображаться главное окно jaeger UI
2. https://localhost:50001/swagger # свагер для service1
[service1 свагер](../Task3/png/service1%20-%20свагер%20и%20end-point%20для%20обращения%20к%20сервису%20service2.png)
3. https://localhost:50001/swagger # свагер для service1
[service2 свагер](../Task3/png/service2%20-%20свагер%20и%20end-point%20получения%20случ%20числа.png)

### Тестирование сервисов
1. Дергаем ручку http://localhost:5001/api/get-random-from-service2 # вызываем ручку service2 через service1 , должны увидеть вот такой результат:
[Выбор и настройка мониторинга в системе](../Task3/png/результат%20обращения%20service1%20к%20service2.png)
2. Идем в jaeger UI выьбираем в списке сервисов Service1 и просматриваем наличие трассировок
[пример трейсинга](../Task3/png/трейсинг%20операции.png)

## Структура проекта
- `services/local/service1/` - Исходный код service1
- `services/local/service2/` - Исходный код service2  
- `services/local/docker-compose.yaml` - развертывание в Docker
- `services/local/prometheus.yml` - Конфигурация Prometeus
